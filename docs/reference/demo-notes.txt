 DEMO TIPS
   * IDS -> IPS: logs read "mode: ids" (detect). Flip the overlay/security
     policy to inline and the same traffic is DROPPED -- strong before/after.
   * HTTP not HTTPS: payload-matching tests use cleartext HTTP/DNS/SNI on
     purpose so the sensor can read them.
   * Expect repeats: DNS retries hit 8.8.8.8 and 8.8.4.4, so one lookup can
     log twice -- normal.

 NOTES ON SIDs

   pinned to a specific SID in the tmNIDS source -- labeled by rule class.
   Hard SIDs (4, 11-15, and 2100498) come from the tool's own comments.
