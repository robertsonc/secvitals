IDS → IPS

Logs read mode: ids (detect). Flip the overlay/security policy to inline and the same traffic is dropped — a strong before/after moment.

HTTP, not HTTPS

Payload-matching tests need cleartext. tmNIDS uses HTTP/DNS/SNI on purpose so the sensor can read them.

Expect repeats

DNS retries hit 8.8.8.8 and 8.8.4.4, so one lookup can log twice — normal.
