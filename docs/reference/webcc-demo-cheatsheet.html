Reading it

EdgeConnect WebCC blocks by silently dropping the flow — there is no block page. So a denied trigger shows as a connection timeout / reset, and an allowed one returns a real HTTP response. The authoritative view is the EC’s Allowed/Denied-by-Category and High-Risk URL/IP stats.

Prereq: set to Deny

A category or reputation band only blocks if the WebCC policy denies it. Allowed categories return HTTP 200.

HTTPS filters by SNI

No decryption needed — WebCC matches the TLS SNI hostname, so HTTPS sites are filtered too.

IP-rep = Tor Proxy

Tor relays are public infra and safely connectable; BrightCloud scores them “Tor Proxy,” a clean IP-reputation trigger.
