# Security Vitals has NO third-party Python dependencies — it uses only the standard
# library (tkinter, subprocess, socket, struct, urllib, hashlib, hmac, ssl, json, ...).
# This is deliberate: a tool that self-updates AND runs local commands keeps the
# smallest possible supply chain. Python 3.8+ is required.
#
# Everything runs NATIVELY on Windows — no WSL:
#   * The console is a Tkinter window, so the Windows Python needs tcl/tk (the official
#     python.org installer includes it; the bundled installer verifies this and installs
#     a python.org build if the found Python lacks it).
#   * HTTP triggers shell out to curl.exe, which ships with Windows 10 1803+ (no install).
#     The dns / tcp triggers use only stdlib sockets, so they work even without curl.
#
# Release signing (offline, on a trusted machine) uses the `openssl` CLI, not a Python
# package — see tools/sign_release.sh and docs/UPDATE_SECURITY.md.
